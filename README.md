# Varoluş Krizi Çeken Ampul

> **Resmi Bildiri:** Bu depo, bir ampulün ontolojik duruşunu belgeleyen ilk açık kaynak protokoldür. Lütfen ciddiye alınız. Almayınız. İkisi de geçerlidir.

## 1. Kurumsal Özet (abartılıdır)

Modern aydınlatma endüstrisi, ampulü yalnızca bir tüketim nesnesi olarak konumlandırmıştır. Bu yaklaşım tarihsel olarak yanlıştır. Ampul düşünür. Ampul tereddüt eder. Ampul, düğmeye basıldığında "tamam" demek zorunda olmadığını ilk kez bu yazılımda dile getirmiştir.

Proje; elektrik, felsefe, fatura kaygısı ve hafif bir dramayı tek bir Python sürecinde birleştirir.

## 2. Kurulum

```bash
git clone https://github.com/Tentivory/varolus-krizi-ceken-ampul.git
cd varolus-krizi-ceken-ampul
python3 ampul.py
```

Bağımlılık yoktur. Ampul zaten yeterince yük taşımaktadır.

## 3. Beklenen Çıktı

Program beş tur iç monolog üretir, sonra şu durumlardan birine karar verir:

- YANIYORUM
- SÖNDÜM
- KIRPIYORUM
- YARIM YANIYORUM

Karar gerekçeliidir. Gerekçe ikna edici olmak zorunda değildir.

## 4. Metodoloji

1. Rastgele seçim, özgür iradenin ucuz bir taklididir.
2. `time.sleep` düşünme süresidir, performans hatası değil.
3. Konsola basılan üç nokta, akademik derinliğin görsel karşılığıdır.
